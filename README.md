# Аня, полетели? Наш маленький Рио

Личное приглашение на свидание в ресторан SOMA. 13 сентября 2026 года, 18:00 (Москва), Петровский бульвар, 14.

React, TypeScript, Vinext, Motion и CSS. Двадцатисекундная анимационная история: бархатный занавес, Голубчик и Жемчужинка, полёт вокруг статуи Христа-Искупителя и над пляжем Рио, карнавал и персональное приглашение. Статический HTML, без базы данных.

## Запуск

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
```

Сайт собирается в статический HTML. Директория публикации задана в `.openai/hosting.json`.

Текст приглашения: `app/page.tsx`. Палитра, адаптивность и анимации: `app/globals.css`. Заголовок страницы: `app/layout.tsx`. Дата в календаре: `public/date-with-you.ics` (15:00 UTC = 18:00 Москва). При изменении даты обновите оба места.

Кнопка сохранения скачивает календарное событие, ссылка на карту открывает Яндекс Карты. У истории есть пауза, пропуск и повтор. При уходе во вкладку анимация и музыка приостанавливаются. Системная настройка уменьшения движения открывает приглашение без полётов.

Музыка: официальный SoundCloud-плеер Interscope Records, «Hot Wings (I Wanna Party)». Воспроизведение запрашивается после нажатия пользователя; если браузер блокирует старт, открывается плеер с прямой кнопкой воспроизведения. Интернет необходим для музыки. Файл трека не копируется в проект.

Графика в `public/rio/` создана через встроенный ImageGen: панорама ночного Рио, два прозрачных четырёхкадровых спрайта персонажей и закрытый театральный занавес. Это оригинальные иллюстрации по мотивам мультфильма, а не вырезанные кадры. Траектории полёта сглажены кубической интерполяцией в `lib/rio-motion.ts`.
