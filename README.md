# Вечер для нас двоих

Личное приглашение на свидание в ресторан SOMA. 13 сентября 2026 года, 18:00 (Москва), Петровский бульвар, 14.

React, TypeScript, Vinext и CSS. Статическая страница, без базы данных и отправки личных данных.

## Запуск

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
```

Сайт собирается в статический HTML. Директория публикации задана в `.openai/hosting.json`.

Текст приглашения: `app/page.tsx`. Палитра, адаптивность и анимации: `app/globals.css`. Заголовок страницы: `app/layout.tsx`. Дата в календаре: `public/date-with-you.ics` (15:00 UTC = 18:00 Москва). При изменении даты обновите оба места.

Кнопка сохранения скачивает календарное событие, ссылка на карту открывает Яндекс Карты. Анимации учитывают системную настройку уменьшения движения. Изображение создано для приглашения и не изображает интерьер ресторана.
