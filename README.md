# Аня, полетели?

Личное приглашение на свидание: SOMA, Москва, Петровский бульвар, 14. 13 сентября 2026 года, 18:00.

React, TypeScript, Vinext, Motion и Three.js. История на 38 секунд: Рио → Хогвартс → море → Нью-Йорк → письмо от Человека-паука. Иллюстрированные фоны, плавные взмахи крыльев, отдельные изображения для телефона. Птицы покидают экран перед сменой локации. При отсутствии WebGL используется Canvas 2D; предусмотрен режим уменьшенного движения.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

## Сборка и публикация

```sh
npm run build
```

Готовый статический сайт находится в `dist/client`. Сервер и база данных не нужны. Изображения и музыка входят в сборку. Музыка запускается после нажатия «Открыть».

### GitHub Pages

Workflow `.github/workflows/pages.yml` собирает сайт после каждого push в `main`. Для адреса с названием репозитория он задаёт `NEXT_PUBLIC_BASE_PATH=/anya-invite`, чтобы работали изображения, музыка, стили и календарь.

На текущем тарифе аккаунта GitHub Pages требует открытого репозитория. Для публикации нужно включить Pages с источником GitHub Actions, установить переменную репозитория `GITHUB_PAGES_ENABLED=true` и запустить workflow. До включения этой переменной выполняется только сборка.

### Netlify

Можно сохранить репозиторий закрытым и импортировать его в Netlify. Файл `netlify.toml` задаёт Node.js 22, команду `npm run build` и папку публикации `dist/client`. Для Netlify переменная `NEXT_PUBLIC_BASE_PATH` не требуется. Доступ к опубликованному сайту настраивается отдельно от доступа к репозиторию.

## Основные файлы

- `app/page.tsx` — текст, приглашение, управление историей и музыкой.
- `lib/cinematic-director.ts` — общий маршрут, время и расстояние между птицами.
- `lib/cinematic-renderer.ts` и `lib/canvas-film-renderer.ts` — два режима анимации.
- `app/globals.css` — оформление и адаптивность.
- `public/date-with-you.ics` — событие календаря (15:00 UTC = 18:00 Москва).

Музыкальный файл предоставлен владельцем проекта. Источники изображений и сведения об атрибуции сохранены в `public/journey/sources.json`, `public/film/sources.json` и `public/audio/source.json`.
