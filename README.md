# Аня, полетели? Маленькое приключение

Личное приглашение на свидание в ресторан SOMA. 13 сентября 2026 года, 18:00 (Москва), Петровский бульвар, 14.

React, TypeScript, Vinext, Motion и CSS. Анимационная история на 38 секунд: занавес открывает Рио; Голубчик и Жемчужинка встречают снитч и летят к Хогвартсу; озеро сменяется морем и греческим кораблём; облака открывают Нью-Йорк, где Человек-паук передаёт конверт «Ане». Конверт раскрывается в приглашение на свидание. Статический HTML, без базы данных.

## Запуск

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
```

Сайт собирается в статический HTML. Директория публикации задана в `.openai/hosting.json`.

Текст приглашения и управление воспроизведением: `app/page.tsx`. Визуальные сцены: `components/film-journey.tsx`. Тайминг и отдельные траектории телефона и компьютера: `lib/story-timeline.ts`. Палитра и адаптивность: `app/globals.css`. Заголовок страницы: `app/layout.tsx`. Дата в календаре: `public/date-with-you.ics` (15:00 UTC = 18:00 Москва). При изменении даты обновите оба места.

На первом экране одна кнопка «Открыть». Кнопка сохранения скачивает календарное событие, ссылка на карту открывает Яндекс Карты. У истории есть пауза и повтор; управление музыкой появляется после начала. Птицы, снитч, частицы, облака, конверт и камера следуют одной шкале времени: пауза останавливает всю сцену. При сворачивании страницы анимация и музыка приостанавливаются. Системная настройка уменьшения движения открывает приглашение без полётов.

На телефоне используются вертикальные изображения 941 × 1672 и отдельные траектории, на компьютере — широкие сцены 1672 × 941. Responsive `picture` выбирает нужный формат; перед началом загружаются только изображения подходящей ориентации и общие спрайты. На коротком экране карточка приглашения прокручивается внутри доступной высоты. При ошибке загрузки графики кнопка открывает само приглашение.

Музыка: официальный SoundCloud-плеер Interscope Records, «Hot Wings (I Wanna Party)». Воспроизведение запрашивается после нажатия пользователя; если браузер блокирует старт, открывается плеер с прямой кнопкой воспроизведения. Интернет необходим для музыки. Файл трека не копируется в проект.

Панорамы Рио, моря и Нью-Йорка, спрайты птиц, снитч, занавес и конверт созданы через встроенный ImageGen. Морская сцена — иллюстрация по мотивам «Одиссеи», не кадр фильма. Изображение облаков — кадрированный фрагмент морской сцены. Траектории полёта сглажены кубической интерполяцией в `lib/rio-motion.ts`.
